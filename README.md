## введение

это библиотека для удобной работы с массивами указателей в языке програмирования C.

## установка

убедитесь что у вас есть компилятор GCC, автотул CMake.

1. сделайте клонирование репозитория с GitHub https://github.com/Germes245/dynamic-array
2. проделайте сборку через инструмент CMake, это можно сделать так:
3. создайте папку build, где будете проводить компиляцию и сборку
4. в терминале находясь выполните команду: **cmake ..**
5. потом сделайте компиляцию и сборку через команду: **cmake --build .**
6. и установку: **cmake --install .**

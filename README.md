## Введение

это библиотека для удобной работы с массивами в языке програмирования C. это не обычный C-код, а шаблон C-кода для работы с любыми типами. для получения кода под определённый тип, подмените символы "{{type}}" на нужный вам тип.

## Установка

убедитесь что у вас есть компилятор GCC, автотул CMake, интерпретатор Python, начиная от версии 3.5.

1. сделайте клонирование репозитория с GitHub https://github.com/Germes245/dynamic-array
2. проделайте сборку через инструмент CMake, это можно сделать так:
13. создайте папку build, где будете проводить компиляцию и сборку
4. в терминале находясь выполните команду: **cmake ..**
5. потом сделайте компиляцию и сборку через команду: **cmake --build .**
6. и установку: **cmake --install .**

или выполните следующие команды (написано под Bash)
```bash
git clone https://github.com/Germes245/dynamic-array.git
cd dynamic-array
mkdir build && cd build
cmake ..
cmake --build .
# (опционально) sudo cmake --install .
```

## Пример использования

```c
#include "dyn_array.h"
#include <stdio.h>

int main() {
    // Создаём массив с начальной ёмкостью 0 (будет расти автоматически)
    dyn_array arr = dyn_array_init(0);
    
    // Добавляем элементы
    size_t a = 10, b = 20, c = 30;
    dyn_array_append(&arr, &a);
    dyn_array_append(&arr, &b);
    dyn_array_append(&arr, &c);
    
    // Получаем элемент по индексу (с проверкой границ)
    size_t ptr = dyn_array_get(&arr, 1);
    printf("Второй элемент: %d\n", *ptr);
    
    // Освобождаем память
    dyn_array_free(&arr);
    return 0;
}
